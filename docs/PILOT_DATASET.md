# Pilot Dataset v0.1

총 30건으로 구성한 파이프라인 검증용 데이터입니다.

| 조건 | 건수 | 목적 |
|---|---:|---|
| NORMAL | 10 | 일반적인 표기에서 기본 처리 확인 |
| VARIANT | 10 | 축약, 기호, 한영 혼용 등 공개 표기 변형 처리 확인 |
| MISSING | 10 | 필수 속성 누락 시 추가 확인 전환 확인 |

## Pilot에서 확인할 것

### 시스템 A
자연어 → LLM 속성 추출 → 필수 속성 검사 → 규칙엔진까지 전체 흐름이 동작하는지 확인합니다.

### 시스템 B
동일한 제조 규칙을 프롬프트로 제공하고 자연어에서 최종 Material/Routing 또는 추가 확인 결과를 직접 생성하는지 확인합니다.

### 시스템 C
정규식·사전으로 속성을 추출한 뒤 시스템 A와 동일한 필수 속성 검사와 규칙엔진으로 처리합니다.

## 사용 원칙

- 이 데이터는 최종 성능 평가용이 아닙니다.
- Pilot에서 발견한 문제는 수정해도 됩니다.
- Pilot의 `VARIANT` 표현은 공개 표현으로 간주합니다.
- 최종 Test의 비공개 표현은 Pilot 이후 별도로 작성합니다.
- 최종 Test 생성 후에는 규칙, 프롬프트, 정규식을 고정합니다.
